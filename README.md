# Uber Data Analytics Dashboard | Power BI

## 📊 Project Overview
This project is an interactive **Uber Data Analytics Dashboard** developed using **Microsoft Power BI**.

The dashboard provides insights into ride bookings, revenue, customers, vehicle types, payment methods, ride distance, and pickup locations.

The main objective of this project is to transform raw ride data into meaningful business insights using data visualization and analytics.


## 🎯 Project Objectives
- Analyze overall ride booking performance
- Track completed and lost bookings
- Analyze revenue generated from rides
- Compare performance across vehicle types
- Understand customer behavior
- Analyze payment methods
- Identify high-performing pickup locations
- Track monthly booking and revenue trends
- Analyze average ride distance



## 🛠️ Tools & Technologies
- **Microsoft Power BI**
- **Power Query**
- **DAX**
- **Data Visualization**
- **Data Analysis**



## 📌 Dashboard Pages

### 1. Overview
The Overview dashboard provides a summary of the overall business performance.

**Key KPIs:**
- Completed Bookings: 93K
- Lost Bookings: 57K
- Revenue: 51.85M
- Total Distance: 2.51M
- Average Distance: 24.64



### 2. Vehicle Analysis
This page analyzes bookings and revenue based on different vehicle types.

**Vehicle Categories:**
- Auto
- Bike
- Go Mini
- Go Sedan
- Premier Sedan
- Uber XL
The analysis helps compare the contribution of different vehicle categories to overall bookings and revenue.



### 3. Rider Analysis
The Rider Analysis page focuses on customer behavior and ride patterns.

It includes:
- Total customers
- First-time riders
- Returning riders
- Regular riders
- Customer revenue
- Payment methods
- Quarterly ride distribution



### 4. Revenue Analysis
The Revenue Analysis page provides insights into revenue performance.

It includes:
- Monthly revenue trends
- Revenue by vehicle type
- Revenue by payment method
- Revenue generated by customers



### 5. Location Analysis
The Location Analysis page focuses on pickup locations.
It helps identify locations with higher booking activity and provides insights into customer pickup patterns.



## 📈 Key Insights
- **Auto** contributes the highest revenue among the displayed vehicle categories.
- **UPI** is the highest revenue-generating payment method.
- Monthly bookings and revenue show variations throughout the year.
- The dashboard shows a mix of first-time, returning, and regular riders.
- Certain pickup locations have higher booking activity than others.
- Vehicle-level analysis helps identify the contribution of each vehicle category.
